6. ENTERPRISE SECURITY SPECIFICATIONS
--------------------------------------------------------------------------------
- Cryptographic Storage: Use `password_hash($pass, PASSWORD_ARGON2ID)`. No MD5/SHA1.
- SQL Injection Immunity: 100% prepared statements via PHP Data Objects (PDO).
- Cross-Site Scripting (XSS): Mandatory `htmlspecialchars()` encoding on all views.
- Cross-Site Request Forgery (CSRF): Cryptographic session tokens on all forms.
- Session Security: `session_regenerate_id(true)`, `HttpOnly`, and `SameSite=Strict`.
- Role-Based Access Control (RBAC): Middleware protecting Admin, Kitchen Staff, 
  and Customer routes against privilege escalation.

10. DEDICATED REAL-TIME APIS
--------------------------------------------------------------------------------
1. Unified Live Location API (`api/live-location.php`):
   - Geodesic spatial calculation tracking rider coordinates from kitchen hub (12.9784, 77.6408)
     to customer delivery address.
   - Interpolates transit milestones, calculating dynamic ETA, remaining distance (km),
     and route progress percentages in real time.
   - `GET ?order_id=...`: Returns current rider GPS coordinates, hub coordinates,
     customer coordinates, bearing, remaining distance, dynamic ETA, and delivery status.
   - `POST action=simulate_step`: Advances rider position by 15-20% along street waypoints.
   - `POST action=update_location`: Accepts raw GPS telemetry (lat, lng) from mobile devices.

2. Unified Live Stream Poller (`api/live-stream.php`):
   - High-performance, lightweight JSON poller servicing all three operations portals:
     - `?portal=kitchen`: Returns incoming orders needing acceptance, active stove timers, and instant counts.
     - `?portal=delivery`: Returns available ready orders awaiting pickup and active transit coordinates.
     - `?portal=admin`: Returns real-time metrics (confirmed, cooking, out for delivery, delivered today, revenue today).
