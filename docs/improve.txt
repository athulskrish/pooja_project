   - Algorithm: Weighted Shortest Job First (WSJF) / Priority Queue.
   - Mechanism: Kitchen staff dashboard dynamically prioritizes tickets based on 
     estimated prep times, customer waiting duration, and order complexity score:
     Priority = (Elapsed Waiting Time * Urgency Factor) / (Sum of Prep Times).

3. Dynamic Delivery ETA Estimation:
   - Algorithm: Multi-Factor Heuristic ETA Calculator.
   - Formula: ETA = Buffer + Max(Prep Time) + (Active Orders * Concurrency Factor) 
     + (Distance Zone Travel Time).

4. Inventory Demand & Stockout Forecasting:
   - Algorithm: Single Exponential Smoothing (SES) / Moving Average.
   - Mechanism: Predicts weekend raw material and dish demand from historical 
     weekday/weekend order patterns to prevent food wastage or stockouts.

6. ENTERPRISE SECURITY SPECIFICATIONS
--------------------------------------------------------------------------------
- Cryptographic Storage: Use `password_hash($pass, PASSWORD_ARGON2ID)`. No MD5/SHA1.
- SQL Injection Immunity: 100% prepared statements via PHP Data Objects (PDO).
- Cross-Site Scripting (XSS): Mandatory `htmlspecialchars()` encoding on all views.
- Cross-Site Request Forgery (CSRF): Cryptographic session tokens on all forms.
- Session Security: `session_regenerate_id(true)`, `HttpOnly`, and `SameSite=Strict`.
- Role-Based Access Control (RBAC): Middleware protecting Admin, Kitchen Staff, 
  and Customer routes against privilege escalation.
